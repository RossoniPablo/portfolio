# Portfólio — Pablo Rossoni

Portfólio profissional desenvolvido com React, TypeScript, Vite e Tailwind CSS.

Site: [pablo-rossoni.vercel.app](https://pablo-rossoni.vercel.app/)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

A saída de produção é gerada em `dist`.

## Publicação na Vercel

1. Envie este projeto para um repositório no GitHub.
2. Importe o repositório na Vercel.
3. Use o comando de build `npm run build`.
4. Use `dist` como diretório de saída.

O projeto inclui metadados para mecanismos de busca, dados estruturados, `robots.txt`, imagem social e cabeçalhos de segurança para a Vercel.
